# Building Blocks (Primitives)
Improvised ideas for various blocks of metalang,

- **Program()** when a program has beginning, it has orientation, and data flow can be more easily followed. this solves so many programming issues and is actually a very human intuitive programming block, we already built this with C's int main. why not formalize it as the actual program itself... so we can interact with it?
- **Fart()...** for comedic effect. code needs more of these toys that exist purely for joy lol.
- **Pattern()...** the ability to save patterns that you can reuse as a semantic "pattern" is one of the things i cognitively reach for, but have to build myself. by the time we created a "class", the idea was lost in translation and documentation...
