# Metalang/Branches
[![](https://img.shields.io/badge/branch-main-orange?logo=github)]() [![](https://img.shields.io/badge/branch-notation-green?logo=github)]() [![](https://img.shields.io/badge/branch-cs-purple?logo=github)]()

A document expressing research development branches of this project.

ML, as a conceptual framework, is not just a language, but rather, research to develop humane technologies, reduce cognitive suffering, and porivde a more stable playground where both research and play can co-exist.

Many branches of ML are planned in the near future, but as of now, this document describes an outline of each developmental branch of ML and it's purposes.

| Branch | Description |
| --- | --- |
| `"main"` | current branch, dedicated mostly to Documentation of ML |
| `"notation"` | an experimental branch of a notation language for programming. |
| `"cs"` | (Conceptual Schematics) is dedicated to sharing programming concepts, rather than rigid frameworks. |
